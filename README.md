# Командировки
Интерактивный прототип подбора перелёта и проживания, проверки бюджета и отправки заявки на согласование.

Сайт работает как статическое приложение. Для локального запуска из корня проекта:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080 и нажмите «Заполнить пример» для маршрута Москва — Казань на 14–16 декабря. Выбор рейсов, цены, согласование и покупка симулируются в браузере. Данные никуда не отправляются.

Для GitHub Pages разместите эти файлы в корне репозитория и выберите главную ветку и / (root) в Settings → Pages.
